# Project Context: Attentive.id Refactor

## 1. Vision & Purpose
Transform the static profile website into a fully integrated consultation management platform for Attentive.id.
- Eliminate manual admin scheduling (WA/Excel).
- Secure and organized screening data.
- Prevent double-booking with calendar integration.
- Track marketing conversions.
