# Phase 1.1: Project Scaffolding & PostgreSQL Integration - Plan

## Goal
Scaffold monorepo apps and set up local PostgreSQL connection.

## Dependencies
None.

## Must Haves
- `apps/api/src/config/env.ts` with TypeBox schema validating `DATABASE_URL`.
- Drizzle ORM setup with connection pooling (`max: 10`, `idle_timeout: 30`).
- Docker Compose configuration to connect `api` to `postgres-shared` via `n8n-network`.
- Blocking DB migration step using manual scripts.

## Threat Model
- Environment variables missing in production could cause silent failures if not validated on boot.
- Over-allocating PostgreSQL connections could crash `postgres-shared` which is used by other services (n8n).
- Missing start script could cause Docker container crash loop in production.

2. Create a minimal `apps/api/Dockerfile`:
   ```dockerfile
   FROM oven/bun:latest
   WORKDIR /app
   COPY package.json bun.lockb ./
   COPY apps/api/package.json apps/api/
   RUN bun install
   COPY apps/api/ apps/api/
   EXPOSE 3000
   CMD ["bun", "run", "start"]
   ```
3. Run `docker compose up -d --build` to build and start the container.
</action>
