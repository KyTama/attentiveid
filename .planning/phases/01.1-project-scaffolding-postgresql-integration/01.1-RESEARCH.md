# Phase 1.1 Research: Project Scaffolding & PostgreSQL Integration

## Current Project State
- Monorepo structure is initialized in the root `package.json` with `apps/api` and `apps/web`.
- `apps/web/package.json` has Vite, React 19, Tailwind v4 (`@tailwindcss/vite`), i18next, and `@elysiajs/eden`.
- `apps/api/package.json` has Elysia, Swagger, and CORS.

## Technical Requirements for Planning

1. **API / Backend (`apps/api`)**
   - **Dependencies**: Need to install `drizzle-orm`, `postgres` (postgres.js), `@sinclair/typebox` or `zod` (for env validation), and `drizzle-kit` as a dev dependency.
   - **Database Setup**:
     - Configure Drizzle with connection limit `max: 10` and `idle_timeout: 30s` (Decision D-05).
     - Use connection string format: `postgresql://<user>:<password>@postgres-shared:5432/attentiveid`.
   - **Migrations**: Create a Drizzle config and set up a migration script (`bun run db:migrate`) using Drizzle Kit (Decision D-03).
   - **Env Validation**: Create `apps/api/src/config/env.ts` to validate environment variables on startup (Decision D-07).

2. **Database & Infrastructure (Root)**
   - **Docker Compose**: Create a `docker-compose.yml` in the project root to manage the `api` (Bun) container and connect it to the external `n8n-network` (to access the `postgres-shared` container) (Decision D-04).
   - **Caddy**: Create a `Caddyfile` for host-level serving, configuring it to serve `apps/web/dist` directly and reverse-proxy `/api/*` to `localhost:3000` or the api container (Decision D-06).

3. **Frontend (`apps/web`)**
   - **Scaffolding**: Complete the Vite + Tailwind v4 setup by scaffolding the core React files (`index.html`, `vite.config.ts`, `src/App.tsx`, `src/index.css`) since the dependencies are already in place but source files might be missing.

## Planning Strategy (aligned with `plan-writing` skill)
- **Be Specific**: Write actionable tasks (e.g., "Install drizzle-orm and postgres in apps/api", "Create apps/api/src/config/env.ts for TypeBox validation").
- **Keep Verification Simple**: (e.g., "Run `bun run db:migrate` and verify it generates SQL", "Curl `/api` on the Docker container").
- **Structure**: Break tasks down independently for backend db config, backend env validation, migrations script, root docker-compose/Caddyfile, and frontend scaffolding.
