## ORM Selection

| Option | Description | Selected |
|--------|-------------|----------|
| Drizzle ORM | Light, TypeScript-first, fast, native Bun integration | ✓ |
| Prisma ORM | Easy to use schema, client generator, Prisma Studio UI | |

**User's choice:** Drizzle ORM (Option 1)
**Notes:** Selected for high efficiency, lower RAM usage, and optimal performance on the target VPS.

## Database Migration Flow

| Option | Description | Selected |
|--------|-------------|----------|
| Manual Migration Scripts | Run SQL migrations manually via command line | ✓ |
| Auto-run Migrations on Startup | Automatically run migrations inside Elysia entry point on startup | |

**User's choice:** Manual Migration Scripts (Option 1)
**Notes:** Recommended for production safety to avoid locking issues under horizontal scaling.

---

## Database Setup

| Option | Description | Selected |
|--------|-------------|----------|
| Shared External Docker Network | Comm. inside internal docker net, port 5432 is not exposed | ✓ |
| Host Gateway Loopback | Expose port 5432 to host localhost, connect via gateway | |

**User's choice:** Shared External Docker Network (Option 1)
**Notes:** Reuses the existing `postgres-shared` container running on the VPS to save RAM. Shared External Network is chosen for maximum security (port 5432 is not exposed to the host/public internet).

---

## Environment Variables Strategy

| Option | Description | Selected |
|--------|-------------|----------|
| Strict Zod/TypeBox Validation | Validate variables on server startup in config/env.ts | ✓ |
| Standard process.env | Access environment variables directly without validation | |

**User's choice:** Strict Zod/TypeBox Validation (Option 1)
**Notes:** Prevents silent runtime failures by failing fast during initialization if settings are missing.

---

## Frontend Serving

| Option | Description | Selected |
|--------|-------------|----------|
| Host-level Caddy Static Serve | Caddy serves React build files directly; API proxied to port 3000 | ✓ |
| Elysia Serving Web | Elysia backend serves React build files via static plugin | |

**User's choice:** Host-level Caddy Static Serve (Option 1)
**Notes:** Highly efficient. Saves RAM and CPU resources in Bun by letting Caddy handle static I/O.

---

## Connection Pooling

| Option | Description | Selected |
|--------|-------------|----------|
| Strict Connection Limit | Set max: 10 pool limit with 30s idle timeout | ✓ |
| Default Connection Pool | Let driver manage connection pool size | |

**User's choice:** Strict Connection Limit (Option 1)
**Notes:** Ensures database connections are not exhausted by either n8n or the api container.

---

## Database Driver

| Option | Description | Selected |
|--------|-------------|----------|
| postgres.js | Pure JavaScript driver optimized for modern runtimes (Bun) | ✓ |
| pg | Standard node-postgres driver | |

**User's choice:** postgres.js (Option 1)
**Notes:** Best performance and lowest memory profile on Bun.
