# Plan 01.3: Internationalization (i18n) Logic

## Goal
Establish complete multi-language support (English & Bahasa Indonesia) for the landing page. This involves properly routing the app to `LandingPage`, standardizing translation keys across all components to match the flat translation files, and extracting remaining hardcoded strings.

## must_haves
- [ ] `App.tsx` routes directly to `<LandingPage />` so that `Navbar` and `LanguageSwitcher` are visible.
- [ ] The `lang` attribute on the HTML document updates dynamically when language changes.
- [ ] All `landing.` prefixes removed from component translation keys; keys accurately map to `en.json` and `id.json`.
- [ ] `Services.tsx` correctly renders the three original therapy categories while preserving Figma UI styles.
- [ ] Hardcoded text in `Contact.tsx` ("View on Maps") and `Footer.tsx` (address, phone, copyright) moved to translation files.
