<domain>
## Phase Boundary

Restructuring the frontend landing page components and porting legacy content to the new Tailwind v4 + Figma design. This phase completely replaces the old layout with the new design system while preserving the existing business content via i18n locales.

<decisions>
## Implementation Decisions

### Component Structure & Order
- Break down the landing page into granular, sequential components.
- The strict vertical order must be:
  1. Hero
  2. About Us
  3. Why Attentive
  4. Psychologists
  5. Testimonials
  6. Services & Download Catalogue
  7. Partner Content
  8. CTA Take the First Step
  9. Clinics Locations

### Figma vs Legacy Content
- **Total Revamp:** The UI must be completely overhauled to strictly match the Figma design.
- If legacy content doesn't fit the Figma layout perfectly, adapt the content to fit the design (Figma wins on layout structure).

### i18n Translation Strategy
- **Immediate Extraction:** Extract all strings into `en.json` and `id.json` immediately. Do not hardcode strings in the JSX.
- **Content Source:** Pull all original content from the legacy YAML file (`attentiveid.github.io/data/en/homepage.yml`).
- **Default Locale:** Use the legacy content to populate `id.json` as the default language base, and ensure `en.json` is populated as well.

### Animations & Scroll Behavior
- **Reveal Animations:** Add scroll-driven reveal animations (fade-up/slide-in on scroll) rather than keeping it static.

### Asset Migration
- **Images/Logos:** Migrate all legacy images from the old project to the Vite `public` folder for a complete port.

### Empty States
- **Fallback UI:** Show a fallback/placeholder UI (e.g. "Coming soon") if a section has no data in the legacy YAML, rather than hiding it entirely.

### the agent's Discretion
- Data mapping logic: How to map the legacy YAML arrays (e.g., psychologists, insights, products) into the specific props required by the new Figma-based React components.
- Component prop interfaces and internal state management.

</decisions>
