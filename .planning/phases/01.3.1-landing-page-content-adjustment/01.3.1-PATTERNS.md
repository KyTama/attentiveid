## 2. Pattern Extracts

### 2.1 Mapping i18n Data to Arrays for UI Rendering
*Reference: `apps/web/src/components/landing/Services.tsx`*
Extracts translation strings into structured arrays before mapping to component props. Useful for `WhyUs.tsx` and dynamic `Contact.tsx`.
```tsx
import { useTranslation } from "react-i18next";
import { Brain, Users, Activity } from "lucide-react";

export function Services() {
  const { t } = useTranslation();

  const services = [
    {
      id: "adult",
      title: t("services.items.adult.title"),
      description: t("services.items.adult.description"),
      icon: <Users className="w-10 h-10 text-primary mb-4" />,
      delayClass: "delay-100"
    },
    // ...
  ];
  // ... mapping
}
```

### 2.2 Standard Section Header Pattern
*Reference: `apps/web/src/components/landing/Psychologists.tsx`*
Consistent typographic pattern for landing page sections.
```tsx
<div className="text-center mb-12">
    <h2 className="text-4xl md:text-5xl font-bold text-foreground mb-4">
        {t('psychologists.title')}
    </h2>
</div>
```

### 2.3 Card UI with Icon Header
*Reference: `apps/web/src/components/landing/Products.tsx`*
Pattern to implement for the new Feature/Why Us cards, or the Insights cards.
```tsx
<Card
    key={product.id}
    className="text-center hover:shadow-lg transition-shadow border-none bg-background"
>
    <CardHeader className="pb-2">
        <div className="w-20 h-20 mx-auto bg-primary/10 rounded-full flex items-center justify-center p-4 mb-4">
            <img src={product.icon} alt="" className="w-full h-full object-contain" />
        </div>
        <CardTitle className="text-lg">
            {t(`products.items.${product.i18nKey}.title`)}
        </CardTitle>
    </CardHeader>
    <CardContent>
        <p className="text-sm text-muted-foreground">
            {t(`products.items.${product.i18nKey}.description`)}
        </p>
    </CardContent>
</Card>
```

### 2.4 Button Call-to-Action Pattern
*Reference: `apps/web/src/components/landing/Contact.tsx`*
Pattern for the `CtaScreening.tsx` component using `Button` as a child wrapper with icons.
```tsx
import { Button } from '@/components/ui/button'
import { MessageCircle } from 'lucide-react'

// ...
<Button
    asChild
    size="lg"
    className="w-full rounded-full bg-green-600 hover:bg-green-700"
>
    <a href={createWhatsAppLink()} target="_blank" rel="noopener noreferrer">
        <MessageCircle className="h-5 w-5 mr-2" />
        {t('contact.whatsappBtn')}
    </a>
</Button>
```
