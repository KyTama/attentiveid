# Phase 01.3.1: Landing Page Content Adjustment - Context

## Objective
Adjust the landing page components and content flow to accurately reflect the provided Figma design, ensuring dynamic text is handled properly via `react-i18next`.

## Key Decisions
- **Hero Image:** Deferred (will use placeholder styling or split layout pending final image assets).
- **"Kenapa memilih Attentive?":** Will be implemented in a new `WhyUs.tsx` component, replacing the old `Services.tsx`. Includes 4 core features from Figma.
- **Clinical Services (Adult/Child/Family):** Moved into the `Products.tsx` component under the title "Informasi Layanan Konsultasi".
- **Catalog Download Link:** Deferred to `#` until a PDF link is provided by the client.
- **Psychologists Display:** Converted from a grid to a horizontal carousel in `Psychologists.tsx` to match the "Tim Psikolog Attentive" design. MUST use the latest list of 17 psychologists.
- **Mental Health Insights:** A new `<Insights />` component will display partner articles from Muzz.
- **CTA Screening:** A new component `CtaScreening.tsx` will be created to house the "Mulai Langkah Pertama Bersama Attentive" section.
- **Dynamic Locations:** The `<Contact />` component MUST be updated to dynamically render the 2 latest clinic locations (Attentive. Jakarta and Attentive. BSD) from configuration/i18n.

## Component Flow
The final rendering order in `LandingPage.tsx` must be:
1. `<Hero />`
2. `<WhyUs />`
3. `<Products />`
4. `<Psychologists />`
5. `<Insights />`
6. `<Testimonials />`
7. `<CtaScreening />`
8. `<Contact />`

## Code Context
- Translation strings will be mapped to `apps/web/src/i18n/locales/en.json` and `id.json`.
- The `WhyUs` object in translations will store the 4 feature cards.
- The `Products` component needs a callout block at the bottom for the catalog download.
- Translations must include the `Insights` data, the 17 `Psychologists` details, and an array for dynamic `Locations`.
