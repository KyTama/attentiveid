# Public Service Catalog Physical Isolation, `appliesNewClientFee` Scoping, and `fixed_variant` Booking Bridge

## Symptoms & Traps
1. **Mixing public client prices with internal fee splits / operational costs (`kind = 'fee' | 'biaya'`)**: Bundling public catalog prices and internal cost rows in one table risks exposing margins, fee splits, or draft/historical pricing via `SELECT *` or over-broad DTOs.
2. **Global `BOOKING_ASSESSMENT_FEE` (`Rp 150.000`) on non-adult-counseling services**: Charging `BOOKING_ASSESSMENT_FEE` unconditionally for all `clientStatus === 'new'` bookings overcharges Child Counseling (`konseling-anak`), Educational Counseling (`konseling-pendidikan`), and fixed-price assessments (`fixed_variant`).
3. **Dropping `fixed_variant` experts with `null` counseling rates (`haykal`)**: `listBookingPsychologists` requires `availableOnline || availableTbi || availableBsd || availableMalang` and non-null rates. Rejecting or hiding `haykal` on `fixed_variant` services (`acm-y48`, `gsc`, `konsultasi-statistik`, `expert-judgment`) or overwriting `fixedBaseRate` with counseling rates breaks expert-linked assessment bookings.
4. **Synchronous `setState` in `useEffect` (`react-hooks/set-state-in-effect`)**: Calling `setLoading(true)` synchronously at the top of a fetch `useEffect` fails React 19 ESLint rules.
5. **Orphaned price rows from archived variants (`v-acm-x`)**: Seeding price records without filtering variants strictly by `status === 'published' && visibility === 'public' && !archived` leaks retired pricing.

## Root Fixes
- **Physical Table Isolation + Explicit DTO Allowlist**: Store only client-facing public prices in `service_public_prices` and `service_program_prices` (zero `fee`, `biaya`, `margin`, `asumsi`, `Historis`, `Usulan` columns or fixtures) and validate API outputs against `additionalProperties: false` TypeBox schemas.
- **Explicit `appliesNewClientFee` Flag on `services`**: Set `appliesNewClientFee: true` solely on `konseling-dewasa` (preserving `true` fallback only when no `serviceSlug` is supplied for legacy direct `/booking`), and gate `BOOKING_ASSESSMENT_FEE` on both `BookingForm.tsx`/`PsychologistPicker.tsx` and `booking.repository.ts`.
- **Model-Aware Psychologist & Rate Resolution**: For `pricingModel === 'fixed_variant'`, keep `eligiblePsychologists` active even when `onlineRate`/`offlineRate` are `null`, auto-default `psychChoice = 'recommended'` when `eligiblePsychologists` is empty, and preserve server-computed `fixedBaseRate` without overwriting from counseling rates.
- **Keyed Async State Derivation**: Track `{ key, data, error }` in component state and derive `loading = state === null || state.key !== currentKey`, updating state only inside async `.then()` / `.catch()` callbacks.
- **Composite Seed Junction Deduplication**: Deduplicate `referenceCodes` and `psychologists` with `Set` before inserting into `service_reference_links` / `service_psychologists` composite PK tables during idempotent seeds.
- **TypeBox Extension Without `additionalProperties` Conflict & `useOptionalAuth`**: When extending strict TypeBox schemas (`additionalProperties: false`) for superadmin internal preview DTOs, spread `BaseSchema.properties` into a new `Type.Object(..., { additionalProperties: false })` instead of `Type.Intersect`; and expose `useOptionalAuth()` in `auth-context.tsx` so public routes supporting optional superadmin toggles render cleanly in unauthenticated Vitest harnesses.
